# 0. Reading rule

This matrix answers four different questions that are easy to conflate:

```text
ENTITY
what concept exists?

TRUTH CLASS
is it source/current/snapshot/projection/infra/ephemeral?

OWNER
which bounded context may redefine its semantics?

STATE
how may it change over time?
```

A physical table name is not automatically frozen by this document. Entity boundaries are target semantics; C6 may stage table names/adapters during migration.

# 16. C5.01 exit criteria

This matrix is complete when implementation planning can answer:

1. which context owns each major entity;

4. what is historically immutable;
5. which state machine applies;
6. which relations are explicitly distinct;
7. which projections can be rebuilt and from what;
